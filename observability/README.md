# observability/

Referencia de observabilidad de la plataforma, alineada a los controles
descritos en
[`docs/04-seguridad-gobernanza.md`](../docs/04-seguridad-gobernanza.md):

- `dashboards/`: tableros de monitoreo de pipelines y de calidad de datos
  con Amazon CloudWatch.
- `alerts/`: alertas de fallo o de incumplimiento de SLA (Service Level
  Agreement) con AWS Step Functions, Amazon EventBridge y Amazon SNS
  (Simple Notification Service), y trazabilidad de accesos con AWS
  CloudTrail.

No contiene configuración funcional. Son placeholders de organización.
